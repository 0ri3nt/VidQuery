# Temporal localization and answerability: Charades-STA + NA-VMR

Evidence date: 25–26 October 2026. Every number is machine-generated by
`scripts/evaluate_moment_benchmark.py` and stored under
`evaluation/results/charades-2026-10-25/`. This benchmark is reported
separately from the AVA action benchmark
([EVALUATION_END_TO_END.md](EVALUATION_END_TO_END.md)): it measures
**temporal localization** of free-form human sentences and **answerability**
(rejecting sentences that do not occur), not action recognition.

## Data, licences, and overlap

| NA-VMR (Flanagan et al., WACV 2025, `keflanagan/MomentofUntruth`) | non-answerable queries aligned to Charades-STA videos: in-domain (Charades sentences from other videos) and out-of-domain | none stated; research evaluation only |

Videos and annotations stay under `data/source/charades/` (gitignored) and are
not redistributed. Source file SHA-256s are recorded in the manifest.

Charades-STA has no validation split, so validation comes from its train
videos; the official train/test split guarantees no video overlap. VidQuery
does not train on Charades, so "train" videos are simply unseen tuning data.
Query wording is the dataset's own; nothing was rewritten.

Each video is indexed end to end from the raw MP4 by the full pipeline
(`scripts/fetch_charades_videos.py` range-reads only the 450 needed videos,
730 MB; `scripts/index_videos_batch.py` indexes them into an isolated
database; 0 failures). Each query searches only its own video, as in the
official protocol. The relation model is pinned to `vidor-relation-pair-visual-gat-v2`
for the whole index.

## Metrics

- **R@k@tIoU** (official): a positive counts if any of the top-k predicted
  intervals has temporal IoU ≥ 0.3 / 0.5 / 0.7 with the ground truth.
  Abstention is ignored (the ranking is scored as if answered).
- **P@1** (VidQuery): a positive counts only if the system **answered** (did
  not abstain) and its top-1 interval has tIoU ≥ 0.5. Without abstention P@1
  equals R@1@0.5.
- **Negative rejection**: a non-answerable query counts as rejected only if the
  system abstains or returns nothing. A weak answer is not a rejection.
- AURC, rejection precision/recall/F1 and answerability AUROC use each query's
  maximum fused confidence.
- **Failure stage** per positive: `no_result`; `correct`; `localization` (top-1
  segment overlaps the moment but tIoU < 0.5); `ranking` (a lower-ranked
  result overlaps it); `retrieval` (nothing retrieved overlaps it).
- 95% CIs: query bootstrap (2,000 samples). Paired differences: video-level
  bootstrap.
- **Content-blind baselines**: a random 5 s segment (expected value) and the
  best fixed fractional window chosen on validation (`[0.1, 0.4]` of the
  video) applied unchanged to test. They show how much the dataset's
  position bias alone gives.

## Validation diagnosis (default system)

Default settings (strict constraints, no frame similarity, Review-2,
5 s segment spans): R@1@0.5 **0.115**, below the fixed window (0.301).
Failure stages over 349 positives: no_result 133, ranking 75, localization 73,
retrieval 28, correct 40. Causes:

1. **Strict AND constraints.** The parser turns "person opens the door" into
   entity/action constraints; a segment missing any one (e.g. YOLO has no
   "door" class) is dropped, so 38% of positives return nothing.
2. **Uninformed ranking.** The surviving evidence is mostly "person" detections
   that every segment has; ties fall back to start time.
3. **Coarse spans.** Charades moments average 8 s (median 7 s, 28% of a
   30 s video); a 5 s segment rarely
   reaches tIoU 0.5 even when it is in the right place.

## Changes (all off by default, validated only)

- **Soft constraint matching** (`SOFT_CONSTRAINT_MATCHING=true`): missing
  entities/actions/relations lower the score instead of rejecting the segment.
- **Frame-level visual-text similarity** (`ENABLE_FRAME_SEMANTIC_RETRIEVAL=true`):
  frozen OpenCLIP ViT-B/32 embeddings of every extracted frame
  (`vidquery/frame_semantics.py`, `scripts/backfill_frame_embeddings.py`;
  ~29 KB per video, 53 s for 299 videos). A segment scores its best frame's cosine with the query
  text, mapped linearly from floor 0.18 to ceiling 0.32. It enters fusion as a
  `visual_semantic` contribution with reliability prior 0.55, and is skipped
  for transcript, OCR, and speaker intents.
- **Span strategy**: `expand:10` reports a 10 s window centred on the top
  segment (clipped to the video).
- **Abstention thresholds** fitted on validation only
  (`scripts/fit_moment_abstention.py`).

### Abstention on validation

Out-of-domain negatives are separable (Review-2 rejects 100% of them with the
default threshold), but in-domain negatives are not: they are real Charades
sentences about the same rooms, objects, and actions, and their confidence
distribution matches the positives (AUROC about 0.6). Fitted thresholds:

| Objective | Weak threshold | Validation P@1 | Negatives rejected | Coverage |
|---|---:|---:|---:|---:|
| balanced (pre-registered primary) | 0.5235 | 0.037 | 0.97 | 0.05 |
| effective reliability | 0.6328 | 0.003 | 1.00 | 0.00 |
| P@1-preserving (post hoc, ≤ 0.01 P@1 loss) | 0.1595 | 0.358 | 0.39 | 0.76 |

The balanced and effective-reliability objectives are degenerate: they buy
rejection by answering almost nothing. The P@1-preserving point was added
after seeing this (validation only) and is reported as a post-hoc choice.

that a single-frame ViT-B/32 score is largely blind to verbs and temporal

### Answerability (NA-VMR negatives)

| System (expand:10) | Abstention | P@1 | In-domain rejected | Out-of-domain rejected | Coverage | Rejection F1 | AURC | AUROC (all / in-domain / out-of-domain) |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| T0 default | default thresholds | 0.150 | 0.552 | 0.998 | 0.32 | 0.767 | 0.879 | 0.637 / 0.540 / 0.735 |
| T1 selected | default thresholds | 0.414 | 0.008 | 0.997 | 0.66 | 0.665 | 0.780 | 0.794 / 0.600 / 0.9995 |
| T1 selected | off | 0.416 | 0.000 | 0.746 | 0.75 | 0.542 | 0.780 | — |
| T2 selected | P@1-preserving (0.1595) | 0.414 | 0.009 | 1.000 | 0.66 | 0.667 | 0.780 | 0.794 |
| T3 selected | balanced (0.5235) | 0.031 | 0.962 | 1.000 | 0.04 | 0.802 | 0.780 | 0.794 |

"Off" still rejects queries that retrieve nothing (out-of-domain queries
often name nothing the parser can match).

- **Out-of-domain negatives are solved** (AUROC 0.9995): sentences such as
  "A long-crested eagle hunts for small mammals in an African savanna" have
  no support in an indoor Charades video.
- **In-domain negatives are not** (AUROC 0.60). T0 appears to reject 55% of
  them, but only because strict constraints return nothing for 48% of
  *positives* as well. The balanced threshold (T3) rejects 96% of them by
  answering only 7.7% of positives.
- **Recommended operating point: T2** (soft + frame, `expand:10`,
  P@1-preserving threshold). It keeps P@1 at 0.414 and rejects every
  out-of-domain negative; in-domain rejection needs a model that checks the
  specific action/object combination, not a different threshold.

### What this supports, and what it does not

- The two changes are complementary and both significant on test: soft
  constraints fix retrieval, frame similarity fixes much of the ranking, and
  together they beat the content-blind fixed window by +0.147 R@1@0.5.
- **P@1 is 0.41 on this benchmark, not 0.8.** Moment-retrieval models
  trained on Charades-STA report R@1@0.5 of roughly 0.40 (older) to 0.60
  (recent DETR-style) on the full test set, without non-answerable queries;
  this 300-video subset is not directly comparable. VidQuery is not trained
  on Charades and indexes 5 s segments, so the gap is expected. Reaching higher needs a temporal grounding model (or
  finer-grained frame/clip embeddings) for ranking and boundary regression,
  not threshold tuning.
- Results are on 300 test videos of indoor household activity with one
  human sentence per moment; they do not transfer to lectures (speech/OCR),
  which are still unlabelled.

## Reproduce

```bash
python -m scripts.build_charades_benchmark            # writes the manifest (already committed)
python -m scripts.fetch_charades_videos --report data/source/charades/fetch.json
export DATABASE_PATH=data/app/benchmark/charades/charades.sqlite3 \
  UPLOAD_DIR=data/app/benchmark/charades/uploads GENERATED_DIR=data/app/benchmark/charades/generated \
  ENABLE_NEO4J=false
python -m scripts.index_videos_batch --manifest evaluation/charades_sta_navmr_benchmark.json \
  --splits validation test --video-dir data/source/charades/videos --progress data/app/benchmark/charades/progress.jsonl
python -m scripts.backfill_frame_embeddings
# validation sweep (repeat per config), then fit thresholds on validation only:
SOFT_CONSTRAINT_MATCHING=true ENABLE_FRAME_SEMANTIC_RETRIEVAL=true \
  python -m scripts.evaluate_moment_benchmark --split validation --spans segment expand:10 --output VAL.json
python -m scripts.fit_moment_abstention VAL.json --key "review2_full|expand:10" --objective balanced --output PRIORS.json
# frozen test, once per configuration:
SOFT_CONSTRAINT_MATCHING=true ENABLE_FRAME_SEMANTIC_RETRIEVAL=true \
  python -m scripts.evaluate_moment_benchmark --split test --spans native segment expand:10 \
  --reliability-priors PRIORS.json --output TEST.json
```

`evaluate_moment_benchmark.py` refuses to overwrite an output file, and
`fit_moment_abstention.py` refuses any input that is not the validation split.
